# Portfolio Site

Personal portfolio built with **React + Vite**, **Tailwind CSS**, and **shadcn/ui**-style components, with **Framer Motion** animations and a tsparticles background.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode with Vite.\
Open [http://localhost:5173/portfolio/](http://localhost:5173/portfolio/) to view it in your browser. The page hot-reloads when you make changes.

### `npm run build`

Builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build locally for a final check before deploying.

### `npm run deploy`

Builds and publishes the `dist` folder to the `gh-pages` branch (GitHub Pages).

## Stack

- [Vite](https://vitejs.dev/) — build tool and dev server
- [React 18](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/) with shadcn/ui-style components in `src/components/ui/`
- [Framer Motion](https://www.framer.com/motion/) — section reveal animations
- [Embla Carousel](https://www.embla-carousel.com/) — project image carousels
- [EmailJS](https://www.emailjs.com/) — contact form
- [tsparticles](https://particles.js.org/) — animated background
